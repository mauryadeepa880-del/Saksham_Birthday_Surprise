# Saksham Birthday Surprise 💗

This project is a small pink-curtain birthday surprise website with a countdown, a birthday PIN, three heart gifts, a friendship message, a five-photo album, and an interactive virtual cake.

## What is needed?
- Anaconda installed on your laptop (Jupyter Notebook is enough).
- No Java, Node.js, VS Code, or extra Python packages are required.
- The HTML/CSS/JavaScript files make the website; the notebook simply starts a local web server for you.

## Run it on your laptop
1. Extract `Saksham_Birthday_Surprise.zip` to a folder.
2. Open Anaconda Navigator and launch Jupyter Notebook.
3. Navigate to the extracted `Saksham_Birthday_Surprise` folder.
4. Open `START_HERE.ipynb`.
5. Run the one cell. It starts the website and prints the address to open. Keep the cell running while using the website.
6. On your laptop, open the printed local address, normally `http://127.0.0.1:8000`.

If the notebook cannot open a browser automatically, copy the address printed in the notebook into Chrome.

## Share it online
For a link that works on your friend's phone through WhatsApp, upload the project folder (the files and `assets` folder together) to a static website host such as GitHub Pages or Netlify. After deployment, send the generated public website link. Jupyter Notebook is used to run it locally; it does not itself create a public internet link.
